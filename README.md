# Yahoo Fantasy Analyzer

A personal, non-commercial tool for analyzing my Yahoo Fantasy Football league using the Yahoo Fantasy Sports API.

## Purpose

This project uses read-only Yahoo Fantasy Sports data to support personal fantasy football analysis, including:

- League settings and scoring rules
- Team rosters
- Available players and waiver status
- Player statistics and projections
- Custom fantasy scoring analysis
- Waiver and roster-management analysis

The primary use case is retrieving available players from my personal Yahoo Fantasy Football league and exporting the data locally for analysis.

## Data Usage

Yahoo Fantasy Sports data accessed by this project is:

- Used only for personal, non-commercial purposes
- Accessed only through authorized Yahoo API access
- Used for analysis of my personal fantasy league
- Not sold, redistributed, or offered as a public data service

## Application

This is a private-use analysis script rather than a commercial application or public service. API access is read-only and intended for a single user and fantasy league.
